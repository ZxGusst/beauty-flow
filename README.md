# BeautyFlow

Sistema web para gestão de empresas do ramo de estética, com foco em agendamentos, administração de equipe e criação de lojas online.

## 📌 Sobre o projeto

O **BeautyFlow** é uma aplicação web desenvolvida para digitalizar e otimizar processos de negócios do setor estético, como salões, barbearias e clínicas.

A plataforma permite:

- Agendamento online de serviços  
- Gestão de horários  
- Administração de funcionários  
- Criação de loja online  
- Painel administrativo para proprietários e equipe  
- Integração com notificações e calendário

## 🏗 Arquitetura

O projeto segue o padrão **MVC (Model-View-Controller)** e arquitetura em camadas:

```text
Frontend (React)
↓
Routes (Express)
↓
Controllers
↓
Models
↓
PostgreSQL
```
